Introduction

The Diabetes Risk Predictor is a binary classification model built to estimate an individual's likelihood of having or developing Type 2 diabetes. It is trained on the Pima Indian Diabetes Database — a benchmark dataset originally collected by the National Institute of Diabetes and Digestive and Kidney Diseases (NIDDK) in the United States.

The model takes six clinical biomarkers as input and outputs a probability score alongside a binary classification label. Alongside the prediction, each result includes a feature attribution breakdown, identifying which input features contributed most strongly — and in which direction — to the decision.

This tool is intended for academic and educational use only. It does not constitute medical advice. Clinical decisions must always involve qualified healthcare professionals.

Dataset Overview

The Pima Indian Diabetes Dataset contains 768 records of female patients, all of Pima Indian heritage, at least 21 years of age. It was originally collected by the NIDDK as part of a long-running longitudinal study of diabetes onset in a high-prevalence population group.

Each row in the dataset corresponds to one patient, and includes the following features: number of pregnancies, plasma glucose concentration (measured two hours after an oral glucose tolerance test), diastolic blood pressure, serum insulin level (measured two hours post-load), body mass index, and age in years. The target variable is a binary outcome: 1 indicates a diabetes diagnosis made within five years of measurement; 0 indicates no diagnosis.

Key Dataset Facts

  • 768 total records; 500 negative (65%), 268 positive (35%)
  • No missing values after preprocessing (zero-value imputation applied to physiological columns)
  • 6 input features: Pregnancies, Glucose, BloodPressure, Insulin, BMI, Age
  • Feature with highest correlation to outcome: Glucose (r = 0.47)
  • Training split: 80% train / 20% test (stratified)

Machine Learning Methodology

The model uses a Support Vector Machine (SVM) with a linear kernel, implemented via scikit-learn's SVC(kernel='linear', probability=True). Prior to training, all features are standardized using StandardScaler to have zero mean and unit variance — a necessary step for SVM, which is sensitive to feature scale.

Feature importance in an SVM context is computed from the signed coefficients of the decision hyperplane. A large positive coefficient indicates that higher values of the feature push the prediction toward the positive class (diabetic); a large negative coefficient indicates the opposite. Glucose dominates with a coefficient magnitude of 0.987, followed by BMI at 0.543.

Training Pipeline

  • Input validation and zero-value imputation for physiologically implausible readings
  • StandardScaler fit on training data only; applied to both train and test sets
  • SVM trained with linear kernel, C=1.0, probability=True for confidence estimation
  • Evaluated using accuracy, F1-score, ROC-AUC, and confusion matrix on a held-out 20% test set

Explainability

Feature attributions are computed at inference time using the formula: attribution = coefficient × z-score. This gives the signed contribution of each input feature to the raw decision score, in comparable units across features. The contributions are returned for every prediction and displayed as a horizontal bar chart in the inference interface.
