Introduction

The Breast Cancer Risk Screener is a probabilistic classification model that evaluates lifestyle and genetic risk factors to estimate an individual's likelihood of developing breast cancer. Unlike imaging-based screening tools, this model operates on tabular clinical data that can be self-reported, making it suitable for population-level risk stratification studies.

The model outputs a binary classification (positive / negative) along with a confidence probability and a feature attribution analysis. This attribution component allows clinicians and researchers to understand which specific factors are most influential in any given prediction — a critical property for adoption in health-adjacent research environments.

This model is for academic and educational use only. It does not constitute medical advice, diagnosis, or screening. Breast cancer screening requires clinical imaging and must be directed by a licensed healthcare provider.

Dataset Overview

The training dataset contains 1,500 de-identified patient records sourced from a validated oncology research cohort. Each record includes seven variables capturing lifestyle behaviors, physiological measurements, and familial risk factors — all established predictors in breast cancer epidemiology literature.

The dataset is structured with seven input features: patient age, body mass index, binary smoking status, genetic risk score (0–2 ordinal scale), weekly physical activity hours, weekly alcohol intake units, and binary prior cancer history. The target variable is binary: 1 denotes a cancer-positive outcome, 0 denotes a negative outcome.

Key Dataset Facts

  • 1,500 total records; 896 negative (60%), 604 positive (40%)
  • No missing values; all features on well-defined ordinal or continuous scales
  • 7 input features covering lifestyle, genetic, and physiological dimensions
  • Highest predictor by Gini importance: Alcohol Intake (0.182) and BMI (0.178)
  • Training split: 80% train / 20% test (stratified)

Machine Learning Methodology

The breast cancer screener uses a Random Forest Classifier, an ensemble method that builds multiple decision trees on bootstrapped subsets of training data and averages their predictions. Random forests are particularly effective for tabular clinical data because they naturally handle non-linear feature interactions and are robust to outliers without requiring feature scaling.

Feature importance is derived from the Gini impurity decrease accumulated across all trees for each feature, providing a consistent, model-native measure of predictive contribution. Alcohol Intake and BMI emerge as the two most important features, consistent with findings in established epidemiological literature on modifiable breast cancer risk factors.

Training Pipeline

  • Stratified 80/20 train-test split to preserve class distribution
  • Random Forest with 100 estimators, max depth unconstrained
  • Gini criterion for split selection; min samples per leaf = 2
  • Evaluated using accuracy, precision, recall, F1, and ROC-AUC on held-out test set

Explainability

At inference time, feature attributions are computed using the formula: attribution = Gini importance × z-score × direction sign. This represents a post-hoc approximation of each feature's directional contribution to the prediction, giving the end user a ranked list of factors driving each individual result.
