REST API Reference

Integrate Quad Analytics models into external workflows. All endpoints accept and return JSON payloads. Stateless inference with zero telemetry retention.

Base URL & Protocol

All endpoints are served over standard HTTP/HTTPS. Requests must include the Content-Type: application/json header for POST endpoints.

Base URL: http://localhost:8000 (Local Development) · Interactive OpenAPI docs available at /docs.

Endpoints Overview

Method Endpoint Description
GET /api/health Platform health check & system status
GET /api/stats Aggregate model metrics and telemetry
POST /api/predict/diabetes Run SVM inference on diabetes biomarkers
POST /api/predict/breast-cancer Run Random Forest oncology screening
POST /api/predict/car-price Estimate used car market valuation
POST /api/predict/ipl-score Forecast IPL match first-innings total
GET /api/dataset/{model_id} Fetch dataset schema and preview rows

Sample Request & Response

Example using /api/predict/diabetes with curl, Python, and JavaScript:

curl -X POST "http://localhost:8000/api/predict/diabetes" \
  -H "Content-Type: application/json" \
  -d '{
    "pregnancies": 2,
    "glucose": 130,
    "blood_pressure": 75,
    "insulin": 35,
    "bmi": 28.4,
    "age": 42
  }'
import requests

url = "http://localhost:8000/api/predict/diabetes"
payload = {
    "pregnancies": 2,
    "glucose": 130,
    "blood_pressure": 75,
    "insulin": 35,
    "bmi": 28.4,
    "age": 42
}

response = requests.post(url, json=payload)
data = response.json()
print("Prediction:", data["prediction"]["result"])
print("Confidence:", data["prediction"]["confidence"], "%")
const res = await fetch("http://localhost:8000/api/predict/diabetes", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    pregnancies: 2,
    glucose: 130,
    blood_pressure: 75,
    insulin: 35,
    bmi: 28.4,
    age: 42
  })
});

const data = await res.json();
console.log(data.prediction);
