Introduction

The IPL Score Forecaster is a regression model that predicts the final first-innings total of an Indian Premier League cricket match given the match state at any mid-innings snapshot. It enables live score projection, which has applications in broadcast analytics, sports betting models, team strategy optimization, and fan engagement platforms.

The model operates on five features that capture the complete match state: batting team identity, bowling team identity, current run rate, wickets lost, and overs bowled. It was trained on a large corpus of historical IPL deliveries to learn the complex, non-linear relationships between match context and eventual total.

Dataset Overview

The training dataset is sourced from Kaggle's comprehensive IPL dataset containing ball-by-ball delivery records from the 2008–2019 seasons. The raw dataset contains 76,014 rows, each representing a single delivery event. For training purposes, a snapshot approach was used: each row of training data represents a match state at a specific over within the first innings.

Features were engineered from the raw delivery log: current run rate (runs scored / overs bowled), wickets fallen at snapshot time, overs bowled, and team encoding. The target variable is the eventual first-innings total for that match. Team names are encoded as categorical variables using the fitted teams.pkl label encoder.

Key Dataset Facts

  • 76,014 raw delivery records; 3,000 rows used for efficient training
  • 8 IPL franchise teams encoded as categorical features
  • Typical first-innings totals range from 130 to 200+ runs
  • Highest correlation to final score: Current Run Rate (r = 0.82)
  • Training split: 80% train / 20% test

Machine Learning Methodology

The model uses a Random Forest Regressor, which handles the non-linear interaction between match state features effectively. Cricket score prediction is inherently non-linear: a team at 100/2 after 10 overs will score very differently from a team at 100/8 after 10 overs, despite identical CRR — demonstrating why tree-based models are well-suited over linear approaches.

Team effects are captured through categorical encoding. The model learns team-specific scoring tendencies through the interaction of batting and bowling team encodings with other features — effectively building team-specific scoring curves implicitly within the ensemble structure.

Training Pipeline

  • Delivery-level aggregation to produce per-snapshot training rows
  • LabelEncoding for batting team and bowling team
  • Random Forest Regressor with 100 estimators
  • Evaluated on held-out test set using MAE, RMSE, and R²

Inference Logic

At prediction time, the user provides the current match state. The model processes team encodings through the fitted teams.pkl LabelEncoder, constructs the feature vector, and produces an estimated final score. Feature attribution is hand-computed from the model's structure: current run rate is the dominant factor with an estimated 52% contribution, followed by overs remaining (21%) and wickets (16%).
